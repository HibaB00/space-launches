## Learn

- **Configuration names encode hardware**: H3-24 = 2 engines + 4 boosters, Ariane 64 = 4 boosters, Vulcan VC6 = 6 solids, Atlas V 551 = 5 solids. Reading them is a real skill.
- **Data vs reference knowledge**: everything from LL2 is data; the engine table is reference knowledge and is labelled so the reader knows which is which.
- **Google Calendar's two doors**: a template URL creates one prefilled event; a `cid=` URL subscribes to a feed that keeps updating. A bare `.ics` link just downloads a file.
- Aerospace: **SRB-3, P120C, GEM 63XL** (solid boosters), **LE-9, Vulcain, BE-4, RD-107/108, Merlin, Raptor** (engines), **thrust-to-weight** must exceed 1.
