# space-launches

Live countdowns to the next 20 orbital launches worldwide. Static site, data baked in by a scheduled build from Launch Library 2.

- `bun install` · `bun run dev` · `bun test` · `bun run build`
- Decisions: `docs/adr/` · Glossary: `CONTEXT.md` · Flown launches: `public/past.json`, generated, carried over from the live site (ADR-0009)
